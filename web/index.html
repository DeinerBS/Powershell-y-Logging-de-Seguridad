Visor de eventos de seguridad

Esta página revisa los eventos de seguridad de Windows y avisa si alguien intentó adivinar una contraseña (fuerza bruta) o si PowerShell marcó un script como sospechoso.

  1. Ejecutar Recolectar-Eventos.ps1 en la VM.
  2. Cargar aquí el archivo JSON que genera.
  3. Ver el resultado en Resumen y Eventos.

      Metodología

      En una máquina virtual con Windows 11 se activó la auditoría de inicios de sesión, procesos, bloqueo de cuentas y scripts de PowerShell. Luego se hicieron intentos fallidos de inicio de sesión contra una cuenta de prueba y el script Recolectar-Eventos.ps1 exportó los eventos a JSON. Esta página aplica la regla "N fallos en X minutos" sobre los eventos 4625 de cada cuenta.
